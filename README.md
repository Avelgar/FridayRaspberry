# 🍓 PiBot (Friday Raspberry Client) — 18 Сервоприводов + Xbox Joystick

Проект превращает вашу "малинку" (Raspberry Pi) в автономного умного робота с голосовым помощником «Пятница», компьютерным зрением (Gemini Robotics ER) и аппаратным управлением 18 сервоприводами.

---

## 🌟 Новые возможности

### 🤖 Управление всеми 18 сервоприводами
* Поддержка **двух плат PCA9685** по шине I2C:
  * Плата №1 (I2C-адрес `0x40`) — каналы 0..8 (9 сервоприводов).
  * Плата №2 (I2C-адрес `0x60`) — каналы 0..8 (9 сервоприводов).
* Калибровка под микросервоприводы **MG90S / SG90** (импульс `500 - 2500 мкс`).
* Потокобезопасная синхронизация через `threading.Lock()` — защита шины I2C от коллизий.
* Плавный ход, волновые танцы и шагающая походка (tripod gait).
* Пятница теперь может двигать **всеми 18 сервоприводами** одновременно при голосовых командах («вперед», «назад», «влево», «вправо», «стоп», «станцуй», «исходное положение»).

### 🎮 Автономное управление с Xbox джойстика (Offline / без Wi-Fi)
* Подключение китайского USB-приемника для Xbox геймпада напрямую в порт Raspberry Pi.
* Служба `JoystickController` работает в фоновом автономном потоке:
  * **Не зависит от наличия Wi-Fi и подключения к серверу**.
  * Если Wi-Fi отключен или пропал, джойстик продолжает мгновенно управлять моторами в реальном времени.
  * Автоматическое обнаружение горячего подключения (hotplug) при включении геймпада или вставке приемника.

#### Раскладка управления геймпада:
* 🕹️ **Левый стик / Крестовина (D-Pad):**
  * Вверх / Вниз — движение вперед / назад всеми 18 сервами.
  * Влево / Вправо — разворот влево / вправо.
* 🕹️ **Правый стик (Вверх/Вниз):**
  * Плавный синхронный наклон ВСЕХ 18 сервоприводов в реальном времени от 0° до 180°!
* 🟢 **Кнопка A:** Исходное нейтральное положение (все сервы в 90°).
* 🔴 **Кнопка B:** Демо-танец / волна всех 18 серв (0° -> 180° -> 0°, как в `test_servo.py`).
* 🔵 **Кнопка X:** Установить все 18 серв в 0°.
* 🟡 **Кнопка Y:** Установить все 18 серв в 180°.
* 🔘 **LB / RB:** Точная ступенчатая подстройка угла серв (-10° / +10°).
* 🔘 **Back / Start:** Экстренная остановка движения (СТОП).

## 🚀 Запуск

### 1. Основной запуск (Пятница + Голос + Зрение + Джойстик):
```bash
python main.py
```
*(Если Wi-Fi отсутствует, голосовой ассистент будет спокойно ждать сеть в фоне, а джойстик продолжит полноценно работать).*

### 2. Автономный тест серв и джойстика (только моторы + джойстик):
```bash
python joystick_control.py
```

### 3. Базовый тест серв:
```bash
python test_servo.py
```

## 🛠️ Советы по китайскому USB-приемнику Xbox на Raspberry Pi
Если после подключения китайского приемника геймпад не находит связь или не создается `/dev/input/js0`:
1. Проверьте видимость USB-устройства: `lsusb`
2. Модуль ядра `xpad` обычно загружается автоматически: `dmesg | grep -i xpad`
3. Если устройство определилось, но не подхватилось `xpad`, выполните:
   ```bash
   sudo modprobe xpad
   ```
4. Проверить отклик осей и кнопок можно утилитой:
   ```bash
   sudo apt install -y joystick
   jstest /dev/input/js0
   ```
