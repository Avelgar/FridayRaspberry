# 🍓 PiBot (Friday Raspberry Client)

Проект превращает вашу "малинку" (Raspberry Pi) в автономного умного робота, наделенного пространственным зрением и возможностью анализировать физический мир.

---

## 🌟 Возможности Робо-Агента

### 🤖 Пространственное зрение (Gemini Robotics ER)
PiBot использует передовую модель **gemini-robotics-er-2-preview**, обученную на реальных данных робототехники.
* **Поиск объектов:** Способность находить любые физические предметы в комнате по запросу.
* **Visual Servoing:** ИИ выдает нормализованные 2D-координаты [Y, X] объектов в кадре для последующего наведения и перемещения к цели.
* **Анализ окружения:** Понимание сцены, препятствий и расположения предметов в пространстве.

### 🎙️ Потоковое зрение и слух (Live API)
Больше никаких локальных задержек!
* **WebSockets Streaming:** Прямая трансляция аудио с USB-микрофона в **Gemini Live 3.1** со скоростью 16000 Hz.
* **Video Streaming:** Мгновенная передача кадров с камеры (через PiCamera2/OpenCV) прямо в "глаза" нейросети с частотой 1 FPS во время диалога.
* Робот "видит" вас прямо во время разговора и может комментировать происходящее вокруг.

### ⚙️ Аппаратное управление
* Поддержка драйверов PCA9685 (Adafruit ServoKit) для управления сервоприводами.
* Выполнение команд `Вперед/Назад/Влево/Вправо` на основе визуальных данных от ИИ-оркестратора.
* Локальное воспроизведение музыки и системных звуков через PyGame.

## 🛠️ Требования к оборудованию
1. **Raspberry Pi** (рекомендуется 4B или 5).
2. **Камера** (Официальная Raspberry Pi Camera Module или USB WebCam).
3. **USB Микрофон** (оптимизировано под Fifine / массивы микрофонов с шумоподавлением).
4. **Мотор-шилд** (I2C 16-Channel PWM/Servo) + Сервоприводы/DC-моторы.
